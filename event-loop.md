# Event Loop (Цикл событий) в JavaScript

Event Loop — это один из ключевых механизмов, позволяющий JavaScript работать асинхронно в однопоточном режиме. Благодаря Event Loop можно выполнять длительные задачи, такие как запросы к серверу, таймеры или обработку пользовательских событий, не блокируя основной поток выполнения.

---

## Как работает Event Loop?

JavaScript однопоточен, то есть в любой момент времени выполняется только одна операция. Для обеспечения асинхронности Event Loop использует следующие структуры:

### 1. **Call Stack (Стек вызовов)**
- Стек вызовов содержит функции, ожидающие выполнения.
- Когда функция вызывается, она помещается в стек.
- Когда выполнение функции завершается, она удаляется из стека.

### 2. **Callback Queue (Очередь обратных вызовов)**
- Когда асинхронная операция (например, `setTimeout`) завершается, её **callback** (функция обратного вызова) помещается в очередь обратных вызовов.
- Очередь работает по принципу FIFO (первый пришёл — первый вышел).

### 3. **Event Loop (Цикл событий)**
- Event Loop непрерывно проверяет:
    - **Call Stack**: Если стек вызовов пуст, он извлекает функцию из очереди обратных вызовов и помещает её в стек для выполнения.
    - Это позволяет обрабатывать асинхронные задачи без блокировки основного потока.
